# DNS Manager (Windows) 🌐⚡

یک ابزار سبک، سریع و کاربردی با رابط گرافیکی (Tkinter) برای تغییر آسان و سریع DNS در ویندوز. این برنامه شامل مجموعه‌ای از برترین DNSهای داخلی (مخصوص دور زدن تحریم‌ها و کاهش پینگ بازی‌ها) و بین‌المللی همراه با امکان بازگردانی تنظیمات به حالت خودکار (DHCP) است.

---

## ✨ ویژگی‌ها (Features)

- **اجرای خودکار با دسترسی ادمین (UAC Admin):** بدون نیاز به راست‌کلیک و انتخاب `Run as administrator`، برنامه هنگام اجرا درخواست مجوز ادمین را صادر می‌کند.
- **بدون پنجره کنسول (Silent & Windowless):** بدون باز شدن صفحه سیاه Command Prompt اجرا می‌شود.
- **دارای ۱۵+ پروفایل DNS پیش‌تنظیم:** شامل رادار، شکن، الکترو، بگذر، کلادفلر، گوگل، Quad9 و سرویس‌های اپراتورهای موبایل.
- **پیش‌نمایش جزئیات و توضیحات:** نمایش آنی آی‌پی‌های اولیه/ثانویه و کاربرد هر DNS پیش از اعمال.
- **بازگردانی به حالت خودکار (DHCP):** امکان ریست کردن سریع DNS به حالت پیش‌فرض مودم تنها با یک کلیک.

## 🚀 نحوه راه‌اندازی و استفاده (Installation & Usage)

### پیش‌نیازها:
- سیستم‌عامل **Windows 10 / 11**
- پایتون نسخه 3.7 به بالا (در صورت اجرای سورس پایتون)

### روش اول: اجرای مستقیم با پایتون

1. فایل پروژه را با پسوند `.pyw` ذخیره کنید (مثلاً `dns_manager.pyw`).
2. کافیست روی فایل **دوبار کلیک** کنید.
3. در پنجره امنیتی ویندوز (UAC)، گزینه **Yes** را انتخاب کنید تا مجوز دسترسی ادمین صادر شود.
4. از منوی کشویی، DNS مورد نظر خود را انتخاب کرده و دکمه **اعمال DNS (Apply)** را بزنید.

> **نکته:** اگر می‌خواهید از طریق ترمینال اجرا کنید، از دستور زیر استفاده نمایید تا پنجره سیاه ترمینال باز نشود:
> ```cmd
> pythonw dns_manager.pyw
> ```

## ⚙️ تغییر کارت شبکه (Ethernet به جای Wi-Fi)

به صورت پیش‌فرض، برنامه تنظیمات را روی کارت شبکه **Wi-Fi** اعمال می‌کند. اگر از کابل شبکه (LAN / Ethernet) استفاده می‌کنید:
1. فایل اسکریپت را با یک ویرایشگر متن باز کنید.
2. خط زیر را پیدا کرده و نام اینترفیس خود را تغییر دهید:
```python
INTERFACE_NAME = "Ethernet"  # یا "Wi-Fi"
```

## 📦 ساخت فایل اجرایی مستقل (.exe)

اگر می‌خواهید این برنامه را بدون نیاز به نصب پایتون در اختیار دیگران قرار دهید، می‌توانید آن را با کتابخانه `PyInstaller` به یک فایل `.exe` تک‌فایل و بدون کنسول تبدیل کنید:

1. نصب PyInstaller:
```cmd
pip install pyinstaller
```

2. ساخت فایل exe با دسترسی ادمین:
```cmd
pyinstaller --noconsole --onefile --uac-admin --name="DNS-Manager" dns_manager.pyw
```

فایل خروجی در پوشه `dist/DNS-Manager.exe` قرار خواهد گرفت.
